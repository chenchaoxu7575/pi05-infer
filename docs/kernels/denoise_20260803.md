## Reproduce

```bash
flock /tmp/pi05_gpu_timing.lock -c '
  nvidia-smi -i 0 -pm 1; nvidia-smi -i 0 -lgc 1900
  PROF_OUT=/tmp/prof CUDA_VISIBLE_DEVICES=0 bash tools/prof.sh cur stage1 12
  nvidia-smi -i 0 -rgc'
tools/ksum.py /tmp/prof/cur.sqlite 157 120
```

WARNING: the driver drops `-lgc` mid-run. Re-apply it every 0.5 s and sample `clocks.sm`
for the whole run; a spread above ~30 MHz voids the data.

WARNING: inductor names a kernel after its whole fusion chain, so the post-attention norm
is called `..._gate_up_geglu_mean_mul_pow_rsqrt_*` and a keyword bucket testing `geglu`
first pulls 18 norm kernels into the GeGLU row. The total stays correct either way. The
`[everything else]` row is derived as `total - the seven named rows`.
